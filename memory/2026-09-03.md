### 测试技巧

- Playwright 的 `fill` / `click` 走真实输入路径,比 `native setter + dispatchEvent` 可靠(TDesign 的 t-textarea/t-input 可能监听 compositionend 或用 modelValue 机制,native setter 不触发 Vue v-model)
- `get_visible_text` 会把 `display:none` 的 Dialog 文本也吐出来,判断 Dialog 是否真 visible 要查 `.t-dialog__ctx` 的 style 属性
- EventSource onerror 触发时机:后端停后几秒内(浏览器重连尝试)
- 后端进程要 `taskkill /F /PID`,Windows 上用 `cmd //c "taskkill /F /PID <pid>"`
