## Bug 修复:会话删除竞态导致 Errno 2(泰哥线上反馈)

**现象**:泰哥在 `/chat/b78bd5c1` 页面发消息收到 `agent run failed: [Errno 2] No such file or directory: ...\\b78bd5c1\\conversation.jsonl`。根因:我测完用 API 删了 `b78bd5c1`,但 mock agent run 线程还在后台跑,`on_append` 继续写已删目录炸了。

**修复**(两层加固):
1. `SessionRegistry.delete(session_id, timeout=5)`:先 pop 内存(挡新 run)→ `sess.lock.acquire(timeout=5)` 等在跑的 run 结束 → 再 rmtree;超时返回 False
2. `ConversationStore.append()`:写前 `mkdir(parents=True, exist_ok=True)` 自愈,目录被外部删也能恢复
3. `app.py delete` 路由:`delete` 返回 False 时查仍存在 → 409 busy,不存在 → 幂等 200
4. `Sidebar.handleDelete`:try/catch,失败 alert"会话正在运行,请等当前回复结束后再删"

**TDD**:4 个新测试先红后绿(append 自愈 / delete 等锁 / delete 超时 / delete 期间 writer 不崩)
**验证**:192 passed(188 + 4 新)、type-check/build 干净、坑记入 lessons-learned.md
