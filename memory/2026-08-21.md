## 第三轮:交互式 shell + Agent trace 输出(2026-08-21 同一天)

### 起因

泰哥测试 `code-reader index` 时发现 summarize 阶段长时间无输出像卡住,体验差。随后问"现在没有 cli 的界面吗",想要持续问答的交互模式。

### 实现(快速收尾)

1. **AgentEvent 类型**(`agent_core/events.py`):4 类事件 LLM_THINKING / TOOL_CALL / TOOL_RESULT / FINAL_ANSWER
2. **AgentService.run(on_event)**:`run(question, on_event=None)`,循环 4 个点发事件
3. **summarize 进度**:每文件摘要完回调打印 `✓ file ok (50字)`/`✗ file fail (...)`
4. **LLM 超时**:llm_client.py `chat.completions.create(timeout=30)`,防挂死 10 分钟
5. **CLI shell 模式**:`code-reader shell --repo <path>`,支持 `/exit` `/reindex` `/help`
6. **ask trace 输出**:默认显示 emoji 中间步骤,`--quiet` 关闭

### CLI 用法(最新)

```bash
# 建索引(现在能看到每文件摘要进度)
code-reader index D:/GoProject/wwBuy

# 单次问答(默认显示 Agent 思考过程)
code-reader ask "main 调了谁" --repo D:/GoProject/wwBuy

# 静默模式
# code-reader ask "main 调了谁" --repo D:/GoProject/wwBuy --quiet

# 交互模式(进 shell 后持续问答)
code-reader shell --repo D:/GoProject/wwBuy
# ask> main 调了谁
# 🤖 正在思考...🔧 调用工具: trace_call_chain
#    ← 返回 128 字节: {"nodes":[{"name":"main",...
# 💡 答案: ...
# ask> /exit
```
