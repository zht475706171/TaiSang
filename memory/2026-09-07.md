## playwright 调试技巧备忘
- `playwright_evaluate` 返回对象会显示 `undefined`(MCP quirk),必须 `JSON.stringify(...)` 包成字符串字面量才回显
- `router.push('/prompts')` 是 Promise,要 `.then()` 读 `currentRoute.value.path`
- 手动 `history.pushState` + `popstate` 不会让 vue-router 响应;要拿 vue 实例 router:`document.querySelector('#app').__vue_app__.config.globalProperties.$router`
- `window.confirm` 可在 evaluate 里 override 来控制确认框返回值 + 捕获消息文本(`window.__confirmMsg = msg; return true/false`)
- TDesign 按钮 class 是 `t-button--theme-primary`(双横线),不是 `theme-primary`
- SSE 验证 broadcast 不必非收事件流:POST 消息后 run 异步跑,直接 GET `/api/sessions/{id}/messages` 看 messages 历史(含 final answer)即可判断 system prompt 是否生效
